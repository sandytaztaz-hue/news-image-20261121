# Sum Up 21

One image that sums up Saturday 21 November 2026: a classic broadsheet front
page with 38 verified stories across 7 regions — 3 big drawn leads (the
missiles that landed in Poland as Kyiv's bridges burned, Wall Street's
freefall as the AI trade unwound, and the M6.7 Peru quake) plus 10 more drawn
stories, a 6-number stat strip, a world map with numbered pins 1–13, the
25-story ALSO ON list (14–38), and a DATE CHECK box for the big stories that
did *not* happen on 21 November. Every story names its source beside it.

The image is `entry.png` (1024×1024). `main.py` copies it to the output
directory byte-for-byte (stdlib only, no network).

Built with Python + PIL; all 13 illustrations are original flat drawings —
no photos, no external images.
